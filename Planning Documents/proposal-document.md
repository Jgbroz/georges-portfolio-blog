## Overview

This document is a simple place for me to throw ideas and begin planning an overall site to showcase skills and projects I am working on. This document will also be commited into the git repo as a means to track and display a fun flow from start of project conception to final piece.

## Aims

- To produce a blog that I can write and track current projects I am working on as a means to publicly display my skill set.
- This portfolio site will encompass multiple projects down the line which can be navigated to from the blog posts I create. This needs to Content manageable on my end to rapidly create posts without frequent code deployments.
- This should bea tool that is easy to navigate to display information about me as an individual. Projects I'm working on. Links to said projects and much more. 
- The site needs to display a degree of competencies such as clean styling, reactive design, a clean backend for maintainability and scalability and easily hosted and deployed to for my own sanity.

## Ideas

- I want this site to show off me as an individual where I can show off my hobbies and projects. For instance I would like to contain differing blog options filtered via a heading so I can create categories in the back end. That way I can produce blog posts for my warhammer painting for instance.
- I would like to create a clean contact me option which will fire off directly to my personal email
- Future projects could include linking my Discord to the site in realtime to allow a clean access to my status as well as interact with a bot that interacts with me as well via DMs.
- Down the line I would like to also utilise the Spotify API in order to show anybody that goes to an end point what I'm listening to with a cute little record player. This view should also provide statistics on the type of music I like.
